# BookShelf Demo Walkthrough

Use this checklist when recording screenshots or walking someone through the live demo.

1. Open the BookShelf home page.
2. Select **Add a New Book**.
3. Add a book with a title, author, and ISBN.
4. Add a second book with a different ISBN.
5. Try submitting a blank form and confirm the required-field validation appears.
6. Try reusing an existing ISBN and confirm the duplicate ISBN validation appears.
7. Open **View All Books** and search by title, author, and ISBN.
8. Edit a book's title or author and save the changes.
9. Delete a book and confirm it no longer appears in the list.
10. Restart the application and observe that the in-memory collection is reset.
